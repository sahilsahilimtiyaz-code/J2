Capabilities

Built to actually do the work

Not a chat window bolted onto Android. Octa-Jarvis reads the screen, plans a few steps and carries them out — with a Stop control always one tap away.

Voice-first, not voice-only

Wake-word listening, streamed speech and barge-in. Interrupt mid-sentence and Jarvis silences himself immediately.

Controls your phone

Opens apps, taps, scrolls and types. Multi-step tasks run through an observe, decide, act and verify loop, capped so nothing runs away.

Taps where you meant

A correction ladder plus a learned per-app offset keep screen control on target, app by app, instead of guessing once.

Answers with no network

An on-device conversational engine handles greetings, follow-ups, arithmetic, memory recall and drafting — no signal required.

Remembers you

Profile facts and extracted memories are recalled into every conversation, and you can read, edit or delete all of them.

Keys stay encrypted

Provider keys live in Android Keystore, memory lives in a local database, and no usage data is sent to us.

Install

Four steps, about a minute

  1. 01

    Download the APK

    Tap the download button. The file lands in your phone’s Downloads folder.

  2. 02

    Allow the install

    When Android asks, allow your browser to install unknown apps. That is normal for a sideloaded build.

  3. 03

    Install over the old copy

    Every release is signed with the same key, so it installs on top of your existing Octa-Jarvis and keeps your data.

  4. 04

    Grant the permissions you want

    Microphone and notifications first. For screen control, enable the accessibility service and allow restricted settings in App info.

After that, updates arrive on their own: the app asks version.json whether a newer build exists, then offers a one-tap download.

Update pipeline

One manifest, every device

Each release is built, tested and signed by GitHub Actions. The workflow rewrites a single manifest, and your installed copy reads it to decide whether to prompt you.

  • Unit tests and assembleDebug run before anything is published.
  • The APK is attached to a GitHub Release and hashed with SHA-256.
  • The manifest carries the version, notes, checksum and a minimum supported build.
  • Skipping a version is remembered on the phone, so the prompt never nags twice.
